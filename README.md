# CariocAce Replay

Pages « une main à deviner » : la main se rejoue toute seule et s'arrête à chaque décision de Hero.
Chaque dossier est une main (`main-2/`, …), accessible à `/<dossier>/`.
Les réponses de la personne partent en notification vers le canal ntfy de `tools/config.json`.

Site statique. Les pages sont générées par `python3 tools/build.py` (voir `CLAUDE.md`).
